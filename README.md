## Overview

Leviathan V2 is a fully autonomous trading system built for individual traders. It connects to your [Alpaca](https://alpaca.markets/) brokerage account and uses a multi-model AI ensemble to scan for opportunities, manage risk, and execute trades — all while strictly respecting Pattern Day Trader (PDT) regulations.

The platform runs as a native desktop application with a modern dark-themed UI, giving you full visibility and control over every aspect of the trading pipeline.

## Key Features

### Autonomous Trading Engine
- **Swing trade execution** with 2–5 day hold periods to avoid PDT violations
- **Smart entry/exit signals** generated by an ensemble of LSTM, N-BEATS, and LightGBM models
- **Dynamic position sizing** that automatically scales with your account performance across 5 tiers (Learning → Maximum)
- **Drawdown protection** that reduces exposure as losses mount, with configurable scaling thresholds

### AI & Machine Learning
- **Multi-model ensemble** combining deep learning (LSTM, N-BEATS) with gradient boosting (LightGBM) for robust predictions
- **FinBERT sentiment analysis** processing real-time news feeds to gauge market sentiment
- **Claude Opus integration** for high-level reasoning about market conditions and trade decisions
- **Self-improving pipeline** that tracks every trade outcome and automatically retrains models on new data

### Cryptocurrency Trading
- **Full support for all 25 Alpaca-supported cryptocurrencies** — BTC, ETH, SOL, DOGE, XRP, AVAX, DOT, LINK, UNI, AAVE, LTC, BCH, SHIB, PEPE, XTZ, BAT, CRV, GRT, SUSHI, YFI, SKY, TRUMP, USDC, USDT, USDG
- **AI-powered crypto scanner** with crypto-specific indicators (7-period RSI, 8/21/5 MACD, Bollinger Bands)
- **Multi-hop swap optimizer** using BFS pathfinding across 60+ trading pairs (max 3 hops, 0.25% fee rate)
- **Portfolio rebalancer** with preset strategies (Conservative, Balanced, Aggressive, BTC Maxi)
- **24/7 automated trading** via background threading

### Options Trading
- **Options chain scanner** with real-time Greeks display (Delta, Gamma, Theta, Vega)
- **Spread strategy builder** supporting verticals, iron condors, and more
- **Intelligent DTE selection** for optimal time-decay management
- **Automated exit management** based on profit targets and stop losses

### Risk Management
- **PDT compliance engine** — never exceeds 3 day trades per rolling 5-day window
- **Circuit breakers** that halt trading when daily loss thresholds are hit
- **Maximum exposure limits** (configurable, default 80% of portfolio)
- **Per-position caps** (configurable, default 30% of portfolio)
- **Wash sale tracking** for tax compliance

### Desktop Application
- **Frameless dark-themed UI** built with HTML/CSS/JS rendered via PyWebView
- **6 dedicated sections** — Dashboard, Analytics, Crypto, Options, Training, Settings
- **Real-time portfolio monitoring** with TradingView-style charts
- **One-click model training** interface with progress tracking
- **Custom window controls** with macOS-style traffic light buttons

## Setup & Installation

### 1. Install Python 3.12

Download and install from the [official Python website](https://www.python.org/downloads/release/python-3120/).

> **Important:** Check **"Add Python to PATH"** during installation.

### 2. Configure API Keys

Copy the example environment file and add your credentials:

```
leviathan/.env.example  →  leviathan/.env
```

Add your Alpaca and Anthropic API keys to the `.env` file.

### 3. Launch

Double-click the included batch file:

```
Setup & Launch Leviathan.bat
```

This will automatically:

1. **Verify Python 3.12** is installed and accessible
2. **Check that pip** is available (installs it if missing)
3. **Install all dependencies** from `requirements.txt`
4. **Launch the application**

Once dependencies are installed, subsequent launches will skip the install step and start instantly.

> **Quick Launch:** If you've already installed dependencies and just want to start the app fast, use `Launch Leviathan.bat` instead.

## Configuration

All trading parameters are configurable in `leviathan/config/settings.py`:

| Parameter | Default | Description |
|---|---|---|
| `STARTING_CAPITAL` | $500 | Minimum starting balance |
| `MAX_POSITION_PCT` | 30% | Maximum single position size |
| `MAX_DAILY_LOSS_PCT` | 3% | Daily loss limit before circuit breaker triggers |
| `MAX_TOTAL_EXPOSURE_PCT` | 80% | Maximum portfolio exposure |
| `HOLD_PERIOD_DAYS` | 2 | Minimum hold period (PDT protection) |
| `MAX_DAY_TRADES_PER_WEEK` | 3 | PDT safety buffer |

### Position Sizing Tiers

The system automatically scales position sizes based on cumulative performance:

| Tier | Base Size | Max Size | Requirements |
|---|---|---|---|
| Learning | 5% | 10% | New accounts |
| Cautious | 8% | 15% | 10+ trades, 45%+ win rate |
| Confident | 12% | 20% | 25+ trades, 52%+ win rate, $5+ profit |
| Aggressive | 15% | 25% | 50+ trades, 55%+ win rate, $15+ profit |
| Maximum | 20% | 30% | 100+ trades, 58%+ win rate, $30+ profit |
